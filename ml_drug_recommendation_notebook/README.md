# Machine Learning Drug Recommendation Notebook

Open `Machine_Learning_Drug_Recommendation_Streamlit.ipynb` in Jupyter Notebook or VS Code.

The notebook:

1. Generates a synthetic healthcare dataset.
2. Trains a Random Forest classifier.
3. Evaluates accuracy and classification performance.
4. Creates prediction probabilities.
5. Adds rule-based safety warnings.
6. Saves the model and metrics.
7. Generates a Streamlit `app.py` file.

Install dependencies:

```bash
pip install pandas numpy scikit-learn joblib matplotlib streamlit jupyter
```

Run the notebook, then start Streamlit:

```bash
streamlit run app.py
```

This is an educational prototype only.
